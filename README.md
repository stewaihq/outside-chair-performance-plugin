# Outside Chair — Performance

Give it the performance files you already use. See what changed, what needs attention and what to do next.

This independently installable plugin connects an authorised host agent to the governed Outside Chair — Performance MCP resource at `https://app.outsidechair.com/mcp/performance`. It contains no credentials, customer data or source documents.

The host agent reads and explains the documents. For a raw-file review, extracted figures and note claims may be retained for up to seven days so the same conversation can answer follow-up questions; the source file is not stored. No governed Performance record is created unless the human asks, reviews the exact proposal and approves it. Confirmed definitions, period closes and management commitments can then carry into later follow-up. Performance keeps company results separate from attribution and never presents management statements as audited or statutory accounts.
